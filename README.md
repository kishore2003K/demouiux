# RS Wellness — Botanical Skincare E-Commerce Website

An animated e-commerce website designed for RS Wellness, featuring slow-ritual botanical skincare.

## Features
- **GSAP & ScrollTrigger Animations**: Staggered typography reveals, parallax imagery, pinned atelier section, and fluid micro-interactions.
- **Preloader Sequence**: Staggered brand typography reveal with 0–100% progress counter and seamless curtain transition.
- **Inertia Carousel**: Touch and mouse drag carousel with momentum physics, variant swatches, and responsive progress tracking.
- **Parabolic Fly-to-Cart Animation**: Dynamic Bezier trajectory animation when adding products to the shopping bag.
- **Slide-out Bag Drawer**: Accessible side-panel cart with quantity management and subtotal calculation.
- **Responsive Layout**: Designed for mobile, tablet, and high-resolution desktop displays.
